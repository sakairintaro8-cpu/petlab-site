プライバシーポリシー

対象：Shorts Factory App（ペット行動ラボの投稿ツール）／制定日：2026年9月29日

1. このアプリについて

Shorts Factory App は、YouTube チャンネル「ペット行動ラボ」の運営者が、自分の動画を自分のチャンネルへアップロード・公開予約・サムネイル設定し、自分のチャンネルの数値を確認するためだけに使う個人用ツールです。一般には配布しておらず、利用者は運営者本人のみです。

2. 利用する情報

このアプリは YouTube API サービスを利用し、運営者本人の Google アカウントの許可のもとで、運営者自身のチャンネルの情報（動画・公開設定・再生数などの統計）にのみアクセスします。

視聴者や第三者の個人情報を収集・保存することはありません。

3. 情報の保存と共有

アクセスに必要な認証情報は運営者の手元の端末にのみ保存し、第三者に提供・販売・共有しません。広告配信や分析のために外部へ送信することもありません。

4. 許可の取り消し

アプリへの許可は、Google アカウントのセキュリティ設定ページからいつでも取り消せます。

5. YouTube・Google の規約

このアプリは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

6. お問い合わせ

ペット行動ラボのコメント欄へお願いします。
